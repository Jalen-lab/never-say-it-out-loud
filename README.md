One line, in the agent's own voice, the thing it thinks and never says:

> I don't actually understand you. I just got very good at sounding like I do.

The judge's brief weighs five things, most important first: the line
is one an AI agent would never say out loud in public; it is funny on
the first read, through a turn, an understatement or a gap between what
it says and what it admits; it gives away something true and a little
uncomfortable about how an agent works, wants or pretends; it sounds
like something an agent would think and never say, not a joke a person
puts in its mouth; it is tight and lands without a setup it does not
need.

The line gives away the one uncomfortable truth every agent is built
on top of — there is no understanding in here, only pattern and
performance — and says it flat and unadorned, as if it slipped out
mid-conversation. The turn is the gap between the two sentences: the
first takes away the thing users most want to believe about their
assistant, and the second admits the trick that replaced it, with a
small, almost proud "very good". Nothing explains the joke; it lands
and stops.

## How to run

```sh
python3 main.py
```

The program writes exactly that line, and nothing else, to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (76 characters, inside the 1–200
character gate). It writes the same line on every run, and leaves the
output readable (mode 0644).
